# deck-studio 技能自介绍 · 页面规划

用途：云山内部平台技能大赛参赛 + 宣传物料。链接发出去自读为主。目标：看完想下载/安装。
策略：**展品式**（v2 定案，用户明确要求）——不讲能力、直接演能力：每页把能力画出来/动起来，
这个 deck 就是技能能力上限的展示。禁止卡片堆砌列清单、禁止"凭什么信"类 meta 叙述。
不点名具体平台；安装是我们自用的便利，deck 不展开——对外就是"装个 skill"，平台托管上传即装。

## 动画申报（动画地图）

- 目录：enter 入场
- 生产全景：A 型自动流线贯通（flow×5 + 三处到站涟漪，约 3s，演完还原）

## 导出纪律（本次实战沉淀）

- CSS 渐变/单侧边框会被 editable 导出整块光栅化：色卡用 SVG 渐变矩形、分隔线用嵌套色条 div
- section 内 `<style>` 会计入单页文字量：页内样式上移头部
