# theme.md — 色板 token 体系（宪法 1：色板主权）

**默认主题 = 蓝色三层体系。** 用户未显式选预设时一律用本体系；选了预设 = 豁免蓝色约束（见 presets.md）。

## 核心原则

颜色只出现在描边、图标、小标签上；背景和卡片用中性灰白。汇报/技术分享场景（老板偏好）永远走本默认。

## Token 定义（生成 deck 时原样抄进 `:root`）

```css
:root {
  /* 三层语义色（信息/执行/保障） */
  --c-info:  #3b82f6;   /* 信息层：上下文管理、状态记忆——"看到什么、记住什么" */
  --c-exec:  #2563eb;   /* 执行层：工具系统、编排系统——"能做什么、怎么协作" */
  --c-guard: #60a5fa;   /* 保障层：反馈系统、沙箱、人机协作——"做错了怎么办" */

  /* 中性色 */
  --bg-card:      #f8fafc;
  --border-card:  #e2e8f0;
  --bg-block:     #f1f5f9;
  --text:         #1e293b;
  --text-sub:     #64748b;
  --text-faint:   #94a3b8;

  /* 错误/危险（仅此语义允许红） */
  --c-danger:        #ef4444;
  --c-danger-bg:     #fef2f2;
  --c-danger-border: #fecaca;
}
```

三层渐变对（卡片填充用，垂直方向从饱和到淡）：

| 层级 | 主色 | 渐变起始 | 渐变结束 |
|------|------|---------|---------|
| 信息层 | `--c-info` | `#dbeafe` | `#bfdbfe` |
| 执行层 | `--c-exec` | `#dbeafe` | `#bfdbfe` |
| 保障层 | `--c-guard` | `#eff6ff` | `#dbeafe` |

## 使用约束

- ❌ 禁止绿、橙、紫等其他色系（除非有明确语义：错误=红系，人工确认节点=琥珀 `#f59e0b` + `#fef3c7`/`#fde68a`）
- ❌ 卡片背景禁止纯色填充——必须用渐变（饱和→淡）
- ❌ 禁止"蓝色家族贯穿全场"等提示设计逻辑的文字——读者不需要知道你的配色逻辑
- ✅ 渐变方向垂直（SVG 用 `x1="0" y1="0" x2="0" y2="1"`，CSS 用 `linear-gradient(180deg, …)`）
- ✅ SVG 图内配色引用 token 对应值：信息层 `#3b82f6`、执行层 `#2563eb`、保障层 `#60a5fa`、中性 `#94a3b8`、错误 `#ef4444`、警告 `#f59e0b`

## 预设覆盖规则

预设（presets.md）只覆盖 `:root` 的 token 值（可增补暗色背景 token），不改组件结构与布局规则。写作任何 deck 时正文引用 `var(--c-*)`，不写死 hex——换主题只动 `:root` 一处。方法论文档吸收进来的示例一律用 token 名表述强调色，不绑定华为红。

**chrome 玻璃材质 token**（`--glass-bg` / `--glass-border` / `--glass-rim` / `--glass-shadow` / `--glass-blur`，定义见 player.md）：默认为浅色液态玻璃；暗色预设必须整体覆盖这组（如 `--glass-bg: rgba(20,28,45,.6)`，rim/shadow 换深色基调），否则玻璃在暗底上发白。

## 品牌模板豁免

品牌模板（如云山）自带完整主题 token 体系（`--ys-*`），整页使用模板 token 即视为显式主题选择，与预设同等豁免蓝色三层默认；内容页新增元素应取模板 token，不引入模板外的新色相。
