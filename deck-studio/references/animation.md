# animation.md — 动画申报制与效果基建（D6 修订 + 常驻流转转正版）

## 一、哲学：动画是叙事工具，不是装饰

动画的全部价值 = 把"讲者的叙述节奏"和"观众的视觉注意"对齐。四个正当用途：**引导注意、信息分块、表达过程、方位连续**。除此之外的一切动画都是冗余。

**一页的默认形态 = 完全静态、整页一次呈现。** 要动画，必须在 Design Spec 申报，且每处能回答三判据之一：

1. 出现时机是否承载讲者的叙述节奏？（分块）
2. 讲到它时是否需要把注意力拉过来？（引导）
3. 它是否表达静态图表达不了的过程/变化？（过程）

答不上来 → 不做。**永不动画**：页标题、eyebrow、页脚、chrome、背景装饰、附录/自读内容。

## 二、效果基建：作者只写三样

引擎与样式已全部资产化（`assets/effects/`），生成 deck 时原样嵌入，**不需要再写任何引擎代码**：

| 资产 | 作用 | 作者要写的 |
|------|------|-----------|
| `assets/effects/effects.css` | fx 高亮/闸口环/脉冲/常驻流转的全部样式 | 无（标记块由 sync-engine 写入） |
| `assets/effects/player.js` 等 JS 五件 | 核心类/步进/自动连播/数字滚动/常驻流转，deck 内 ═══ DECK ENGINE ═══ 标记块 | 无（严禁手改）+ `DECK_STEPS`/`DECK_AUTO`/`DECK_COUNTUP`/`DECK_AMBIENT` 数据声明 |
| `references/player.md` | 播放器壳（浏览/放映双模式、缩略图、聚光灯） | 无（照 player.md 实现） |

**作者的三样输入**：

1. **图**——按 svg-diagrams.md 画；节点坐标就是动画路线的数据来源；
2. **数据**——`window.DECK_STEPS`（步进程序）与 ambient.js 参数区（回路路线/节奏常量），格式见下；
3. **理由**——每处动画在 Design Spec 里申报三判据之一（分块节奏/引导注意/表达过程），无理由不申报。

**你不用管的**（已内置）：终态还原（动画演完=静态整页，门禁/截图/缩略图/导出零适配）、讲者主权（点击快进、闸口确认、reduced-motion 静态）、离页暂停、性能（transform/opacity 合成层）、深浅主题（fx 色值随 token）。

## 三、八机制词表

| 机制 | 接口 | 类型 | 适用 | 案例（数据交付 Agent deck） |
|------|------|------|------|------|
| 巡游 `t` | DECK_STEPS | 流转+状态 | **线性**流程页——把核心论点走一遍 | 流水线贯通+闸口停顿 |
| **常驻流转** | AMBIENT 参数区 | 流转+状态 | **闭环/迭代**机制页——回路活流程，每周期走全部分支后到产出节点 | 螺旋回路：报错回改→校验回改→人判回改→通过交付 |
| 走查 `w` | DECK_STEPS | 状态 | 密集表格/矩阵/静态大图——**常驻不藏**，讲到哪点亮哪（多区域=联动） | 平台表逐行；矩阵逐行；接点清单↔回路图 |
| 分块 `c` | DECK_STEPS / reveal | 出现 | 并列论元按完整论断逐个出（拒绝逐条小装饰） | 三条红线 ×3 |
| 脉冲 `pulse` | DECK_STEPS | 引导 | 点名阻塞/风险，只此一次 | ⚡阻塞项红格 |
| 状态变更 | 巡游 `state` / overlay | 状态 | 达标、迁移、对比 | 代码稳定浅→深蓝 |
| 双光点 `move2` | 巡游微指令 | 流转 | 并行汇合（同时出现=并行语义） | 两入口合流 |
| count-up | DECK_COUNTUP（countup.js） | 状态 | 数字本身是论点时 | 成果页六数、价值倍数：进页 0→真值，终帧=原文 |

### 流线语言法则（2026-09-24 定案，tech-review deck 审美裁决）

动画住在**箭头**上：`flow` 让一段"被撑大的线"沿连线从起点流转到终点后消失（扇出用 `flows` 并行），
到站一个短暂脉冲（fpulse，~750ms 即逝），演完页面 **100% 恢复原样**。光点飞行（`move`）同步退役——
用户裁决是"箭头在变化"，不是点在飞。**lit / wseq / w / state / veil 等持久染色机制同样退役**
（引擎保留兼容旧 deck），讲者强调用放映聚光灯（P）。auto 序列绑定进页时的页号，换页即作废
（防串页）。流转页 ambient 光点巡航经用户认可，保留。

## 四、节奏常量（科学依据，均为具名常量可调）

| 常量 | 值 | 依据 |
|------|-----|------|
| 光点速度 | 200 单位/s | 视觉平滑追踪舒适区 ~30°/s 视角（3m 观看/2.5m 宽幕 ≈ 全屏 2~4s 横穿），沿线需读标签 |
| 判定停留 | 500ms | 标签识读 ≥400ms |
| 闸口停留 | 950ms | 语义"等人"，需明显长于判定 |
| 周期交付后休息 | 1800ms | 持续运动内容需可感知的停顿节拍（WCAG 2.2.2 精神） |
| 入场/移动 | 300–650ms | 快而可追随；600ms+ 慢淡入只留给章节戏剧时刻 |
| 整页放完 | ≤3s | 超过即绑架讲者节奏 |

## 五、作者接口 1：DECK_STEPS（步进程序）

```html
<script>
window.DECK_STEPS = {
  '页label': [
    ['sumhide', [x,y,w,h]],                                              // 结论条遮盖：放映态进页即自动置位（不消耗点击；浏览态恒显）
    ['t', [ ['veil',[x,y,w,h]], ['lit',rect], ['move',x1,y1,x2,y2,ms],
            ['gate',x,y], ['back',x1,y1,x2,y2,ms], ['state',rect] ]],   // 巡游（gate=停顿等确认）
    ['w', [x,y,w,h], [x2,y2,w2,h2]],                                    // 走查（第二个区域=联动）
    ['wseq', [[rect],[rect],...], 900],                                  // 自动连播走查：一次点击逐个点亮（可快进）
    ['c', '.selector'],                                                  // 分块（.reveal 标记为已放出）
    ['pulse', [x,y,w,h]],                                                // 一次性脉冲
    ['sumshow'],                                                         // 结论揭示（末拍：遮盖淡出，结论落地）
  ],
};
</script>
```

坐标用所在 SVG 的 **viewBox 坐标**。预算：一页 0–3 步常态、硬上限 5（含巡游闸门）；场景差异：授课充分用、汇报页均 ≤1 步、自读零动画。

## 五、触发模式：自动播放型 vs 讲解同步型

每个动画还要选**触发方式**（为谁演）：

| 模式 | 触发 | 适合 | 案例 |
|------|------|------|------|
| **A 自动播放** | 页面成为当前页时自动演一遍（可点击快进） | **过程自解释**的内容——画面自己会说话 | 流水线贯通、主干扫过、融合点汇聚、机制回路（常驻） |
| **B 讲解同步** | 点击步进，配合讲者节奏 | **需讲者展开**的论元/对比/清单 | 矩阵行走查、红线步进 |

规则：巡游/连播/脉冲类默认 A；走查/分块默认 B、可声明为 A；无遮罩是 A 型默认形态（全图常亮，运动即表达）。

## 六、构建时序：定稿后动画构建（workflow）

1. **生成期**：内容页**纯静态**生成，零效果资产嵌入；spec 阶段完成**动画地图**申报（意图前置——画图时为路线留好结构，但不构建）；
2. **多轮修改**：只改内容，动画零负担；
3. **定稿后动画构建**（独立工序）：`node deck-studio/scripts/sync-engine.mjs` 写入引擎标记块 + 填 `DECK_STEPS`/`DECK_AUTO`/`DECK_AMBIENT` 数据 + 跑门禁/e2e。内容后续小改不动动画；结构大改才同步声明数据。

（依据：多轮讨论期构建动画是纯损耗——每次内容变更都牵连动画返工；资产化+数据驱动让动画构建成为定稿后的半日的轻工序。）

## 七、该动 / 不该动（判据清单，判例来自 emp deck 审计）

判定单位是**内容元素**，不是页——同一页上融合图该动、参考表不该动，可以共存。

**该动**（内容含过程，或讲者确需控制节奏）：

| 内容 | 机制 |
|------|------|
| 闭环/迭代机制回路 | 常驻流转 |
| 线性流程主干 | 巡游连播 |
| 并行汇合 | 双光点 |
| 讲者逐条展开的并列论元 | 走查/分块（B） |
| 数据揭示 | slow reveal / draw / count |
| 照片页（可选） | Ken Burns 轻缓动 |

**不该动**：封面/结束页/章扉画面本体；页标题/eyebrow/页脚/chrome；**参考型表格/矩阵**（整体阅读价值 > 逐行跟随，协同页平台表判例）；**清单类次要内容**（形态页 UT 判例：为动而动）；背景装饰；附录/自读内容。

### 动画地图（一致性原则，Mayer 相干性/信号性）

申报前先画**全 deck 动画地图**：哪几页演、各用什么机制、哪些页明确静态。两条校验规则：

1. **同类型同待遇**——相同内容类型（如全部流程图）用同一机制；两个流程图一个演一个不动 = 打断观众预期；
2. **孤立动画页 = 叙事高峰才成立**——全 deck 只有一页动画时，该页必须是叙事核心（唯一的机制/过程页），此时动画是信号而非噪音；否则把动画扩展到同类页，或干脆全部静态。

（依据：MIT 传播实验室 "less is more"；Mayer 相干性原则——多余动画增加外在认知负荷；信号性原则——动效应指向 essential 内容。）

## 作者接口：DECK_COUNTUP（数字滚动）

```html
<script>
window.DECK_COUNTUP = {
  '页label': { ms: 1200, items: [[x, y], ...] },   // (x,y) = 页 svg <text> 的坐标属性
};
</script>
```

进页从 0 滚到真值（easing-out，多数字轻错拍），文本解析为「前缀+整数+后缀」只滚整数
（`50+`、`≈3~5×` 均可）；**终帧严格还原原文**。坐标没匹配到 text 就静默跳过。

## 六、作者接口 2：AMBIENT 参数区（常驻流转）

仅限**闭环/迭代**内容，每 deck 至多一处。路线支持单判定 `decide` 或多点判定 `decides`
（`{序号: {ms, gate, then}}`——色彩只由判定驱动，可编排「一条路线走满全部回路」的连续剧，
如 tech-review 流转页「最复杂的一天」）。引擎在标记块内（勿改），作者只声明 `window.DECK_AMBIENT` 数据：`pageLabel`、`speed`、`decideMs`、`gateMs`、`restMs`、`routes`（回路路线按演示顺序，`backFrom` 标打回段、`decide` 声明判定停顿与转向）、`nodes`、`stateAt`/`stateRect`。完整格式见文件内注释。红线：离页必停（已内置）、reduced-motion 静态（已内置）、禁止循环闪烁装饰。

## 七、语义参数（动画参数就是语义参数）

| 参数 | 语义 |
|------|------|
| 正向流动 | 自动执行、推进 |
| 反向流动（红） | 退回、重做、失败路径 |
| 停顿 | 等人、等待决策 |
| 同时出现（move2） | 并行 |
| 变色/状态 overlay | 状态迁移、达标、阻塞 |
| 一次性脉冲 | 点名注意（只此一次，绝不循环；常驻流转的节点脉冲除外——它随光点节拍） |

## 八、工程不变式（维护者条款——作者无需关心）

1. **终态不变式**：任何动画演完 = 静态整页；fx/ambient 层清空即还原。门禁/截图/缩略图/导出只见终态；
2. **讲者主权**：动画中点击 = 快进到该动画终态；闸口点击 = 确认继续（语义消费）；`prefers-reduced-motion` 直达终态；
3. **暂停必推进索引**：任何"停一拍"实现必须先推进路由/步进索引再等待——否则无限折返卡死（本项目踩过两次：闸口、判定分叉）；
4. **命名隔离**：fx 元素缓存属性勿与方法同名（`fxToken` 冲突曾致巡游卡死，令名 `newToken`）；
5. **零叠加线条**：原图已有的线不为动画重画；运动的可见物只有光点与高亮 overlay；
6. **声明式**：动画是数据不是散落 JS——与 AICO data-step 语义同构，为导出逐拍留接口。
