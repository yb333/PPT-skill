# animation.md — 动画申报制与效果基建（D6 修订 + 常驻流转转正版）

## 一、哲学：动画是叙事工具，不是装饰

动画的全部价值 = 把"讲者的叙述节奏"和"观众的视觉注意"对齐。四个正当用途：**引导注意、信息分块、表达过程、方位连续**。除此之外的一切动画都是冗余。

**一页的默认形态 = 完全静态、整页一次呈现。** 要动画，必须在 Design Spec 申报，且每处能回答三判据之一：

1. 出现时机是否承载讲者的叙述节奏？（分块）
2. 讲到它时是否需要把注意力拉过来？（引导）
3. 它是否表达静态图表达不了的过程/变化？（过程）

答不上来 → 不做。**永不动画**：页标题、eyebrow、页脚、chrome、背景装饰、附录/自读内容。

## 二、效果基建：作者只写三样

引擎与样式已全部资产化（`assets/effects/`），生成 deck 时原样嵌入，**不需要再写任何引擎代码**：

| 资产 | 作用 | 作者要写的 |
|------|------|-----------|
| `assets/effects/effects.css` | fx 高亮/闸口环/脉冲/常驻流转的全部样式 | 无（整体粘贴） |
| `assets/effects/stepfx.js` | 步进程序执行器（分块/走查联动/脉冲/巡游含闸门停顿） | 无（整体粘贴）+ `window.DECK_STEPS` 数据 |
| `assets/effects/ambient.js` | 常驻流转控制器（闭环内容活流程） | 无（整体粘贴）+ 参数区数据 |
| `references/player.md` | 播放器壳（浏览/放映双模式、缩略图、聚光灯） | 无（照 player.md 实现） |

**作者的三样输入**：

1. **图**——按 svg-diagrams.md 画；节点坐标就是动画路线的数据来源；
2. **数据**——`window.DECK_STEPS`（步进程序）与 ambient.js 参数区（回路路线/节奏常量），格式见下；
3. **理由**——每处动画在 Design Spec 里申报三判据之一（分块节奏/引导注意/表达过程），无理由不申报。

**你不用管的**（已内置）：终态还原（动画演完=静态整页，门禁/截图/缩略图/导出零适配）、讲者主权（点击快进、闸口确认、reduced-motion 静态）、离页暂停、性能（transform/opacity 合成层）、深浅主题（fx 色值随 token）。

## 三、八机制词表

| 机制 | 接口 | 类型 | 适用 | 案例（数据交付 Agent deck） |
|------|------|------|------|------|
| 巡游 `t` | DECK_STEPS | 流转+状态 | **线性**流程页——把核心论点走一遍 | 流水线贯通+闸口停顿 |
| **常驻流转** | AMBIENT 参数区 | 流转+状态 | **闭环/迭代**机制页——回路活流程，每周期走全部分支后到产出节点 | 螺旋回路：报错回改→校验回改→人判回改→通过交付 |
| 走查 `w` | DECK_STEPS | 状态 | 密集表格/矩阵/静态大图——**常驻不藏**，讲到哪点亮哪（多区域=联动） | 平台表逐行；矩阵逐行；接点清单↔回路图 |
| 分块 `c` | DECK_STEPS / reveal | 出现 | 并列论元按完整论断逐个出（拒绝逐条小装饰） | 三条红线 ×3 |
| 脉冲 `pulse` | DECK_STEPS | 引导 | 点名阻塞/风险，只此一次 | ⚡阻塞项红格 |
| 状态变更 | 巡游 `state` / overlay | 状态 | 达标、迁移、对比 | 代码稳定浅→深蓝 |
| 双光点 `move2` | 巡游微指令 | 流转 | 并行汇合（同时出现=并行语义） | 两入口合流 |
| count-up | 自写（15 行） | 状态 | 数字本身是论点时（罕见） | — |

## 四、节奏常量（科学依据，均为具名常量可调）

| 常量 | 值 | 依据 |
|------|-----|------|
| 光点速度 | 200 单位/s | 视觉平滑追踪舒适区 ~30°/s 视角（3m 观看/2.5m 宽幕 ≈ 全屏 2~4s 横穿），沿线需读标签 |
| 判定停留 | 500ms | 标签识读 ≥400ms |
| 闸口停留 | 950ms | 语义"等人"，需明显长于判定 |
| 周期交付后休息 | 1800ms | 持续运动内容需可感知的停顿节拍（WCAG 2.2.2 精神） |
| 入场/移动 | 300–650ms | 快而可追随；600ms+ 慢淡入只留给章节戏剧时刻 |
| 整页放完 | ≤3s | 超过即绑架讲者节奏 |

## 五、作者接口 1：DECK_STEPS（步进程序）

```html
<script>
window.DECK_STEPS = {
  '页label': [
    ['t', [ ['veil',[x,y,w,h]], ['lit',rect], ['move',x1,y1,x2,y2,ms],
            ['gate',x,y], ['back',x1,y1,x2,y2,ms], ['state',rect] ]],   // 巡游（gate=停顿等确认）
    ['w', [x,y,w,h], [x2,y2,w2,h2]],                                    // 走查（第二个区域=联动）
    ['c', '.selector'],                                                  // 分块（.reveal 标记为已放出）
    ['pulse', [x,y,w,h]],                                                // 一次性脉冲
  ],
};
</script>
```

坐标用所在 SVG 的 **viewBox 坐标**。预算：一页 0–3 步常态、硬上限 5（含巡游闸门）；场景差异：授课充分用、汇报页均 ≤1 步、自读零动画。

## 六、作者接口 2：AMBIENT 参数区（常驻流转）

仅限**闭环/迭代**内容，每 deck 至多一处。整体粘贴 `ambient.js` 后只改参数区：`PAGE_LABEL`、`SPEED`、`DECIDE_MS`、`GATE_MS`、`REST_MS`、`ROUTES`（回路路线按演示顺序，`backFrom` 标打回段、`decide` 声明判定停顿与转向）、`NODES`、`STATE_AT/STATE_RECT`。完整格式见文件内注释。红线：离页必停（已内置）、reduced-motion 静态（已内置）、禁止循环闪烁装饰。

## 七、语义参数（动画参数就是语义参数）

| 参数 | 语义 |
|------|------|
| 正向流动 | 自动执行、推进 |
| 反向流动（红） | 退回、重做、失败路径 |
| 停顿 | 等人、等待决策 |
| 同时出现（move2） | 并行 |
| 变色/状态 overlay | 状态迁移、达标、阻塞 |
| 一次性脉冲 | 点名注意（只此一次，绝不循环；常驻流转的节点脉冲除外——它随光点节拍） |

## 八、工程不变式（维护者条款——作者无需关心）

1. **终态不变式**：任何动画演完 = 静态整页；fx/ambient 层清空即还原。门禁/截图/缩略图/导出只见终态；
2. **讲者主权**：动画中点击 = 快进到该动画终态；闸口点击 = 确认继续（语义消费）；`prefers-reduced-motion` 直达终态；
3. **暂停必推进索引**：任何"停一拍"实现必须先推进路由/步进索引再等待——否则无限折返卡死（本项目踩过两次：闸口、判定分叉）；
4. **命名隔离**：fx 元素缓存属性勿与方法同名（`fxToken` 冲突曾致巡游卡死，令名 `newToken`）；
5. **零叠加线条**：原图已有的线不为动画重画；运动的可见物只有光点与高亮 overlay；
6. **声明式**：动画是数据不是散落 JS——与 AICO data-step 语义同构，为导出逐拍留接口。
